# RPyS

A basic web game of Rock Paper Scissors, complete with an account system, leaderboards, and the worst anticheat physically developable.
<br><sub>except for Watchdog ;)</sub>

Made with Python, HTML, horrible JS, even worse templating, and love 💖

## Install
Get the project:
```
git clone github.com/LushAlaz/RPyS.git
```
Use virtual environment and install dependencies:
```
python -m venv .env
.env/Scripts/activate (.bat for cmd, .ps1 for powershell, nothing for bash)
pip install -r requirements.txt
```
Run the project:
```
python rpys.py
```
